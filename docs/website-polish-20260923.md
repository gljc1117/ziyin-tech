# 官网定位与体验改版

定位：面向医院的数智医学产品与医工转化服务商。

首页按产品、项目实践、中心与科研协作、三类动态、联系合作组织。新增 `/products` 及四个产品详情页，产品入口可预选咨询需求。新闻页最大容器1320px，配成果侧栏、分类及搜索；完整原标题和正文保留。

视觉调整沿用品牌标志、深蓝和青色，以真实资料图片和公开模型展示工作内容。模型交互按需加载；静态图不依赖 WebGL。全站联系入口统一为“联系合作”。

咨询接口与Supabase持久化逻辑未改写，仅增加需求类型。先需求后联系方式的表单保留原字段兼容，月手术量默认“不适用”；仅后端确认保存成功才显示成功。

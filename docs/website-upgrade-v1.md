## 公众号资料接入
当前浏览器安全策略禁止访问微信公众平台；没有登录、抓取、后台写入或取得后台数据。本方案不保存后台登录链接、token、Cookie或密码。
请负责人自行导出或将文章保存为Word/PDF，连同原始图片上传。优先：公司介绍与资质、医院/科室合作、医工造物交付、CalcAI产品介绍、数智医学中心项目。

状态：待整理 → 待核验 → 已审核 → 已发布；撤回内容保留记录。采集不等同于发布。
同一项目新闻和案例通过content_id关联；新闻表达事件，案例表达需求、过程、交付与证据，避免两份资料各自改写。
